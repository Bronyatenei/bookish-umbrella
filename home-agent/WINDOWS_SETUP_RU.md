# Windows Home Agent: установка, тест и автозапуск

> **Назначение.** Home Agent запускается на домашнем Windows-компьютере, раз в заданный интервал проверяет Twitch-каналы и посылает телефону high-priority FCM-событие при переходе канала из offline в live. В режиме **«Домашний агент — проверки на ПК»** телефон не опрашивает Twitch самостоятельно, поэтому не тратит заряд на периодические сетевые проверки.

## Что потребуется

| Компонент | Для чего нужен | Где взять |
|---|---|---|
| Последняя APK Twitch Alarm | Принимает FCM-событие и включает тревогу | Из последней сборки приложения |
| Windows-компьютер | Постоянно запускает проверку Twitch | Ваш домашний ПК; он должен быть включён и иметь интернет |
| Node.js 22 LTS или новее | Запускает Home Agent | [Официальная страница Node.js](https://nodejs.org/) |
| Firebase service account key | Даёт ПК право отправить FCM на ваш телефон | Firebase Console, шаг 3 ниже |
| FCM-токен телефона | Указывает, на какой конкретно телефон отправлять событие | Настройки Twitch Alarm, шаг 4 ниже |

> **Не присылайте в чат и не публикуйте в GitHub** файлы `service-account.json`, `config.json` и `state.json`. Первый содержит приватный ключ Firebase, второй — токен вашего телефона. В проекте они исключены из Git, но это не защищает файл, если его вручную куда-то отправить.

## 1. Получите исходники Home Agent

Выберите один способ.

| Способ | Когда удобен | Действия |
|---|---|---|
| Скачать ZIP | Нужен самый простой однократный запуск | Откройте [Pull Request №2](https://github.com/Bronyatenei/bookish-umbrella/pull/2), нажмите **Code → Download ZIP**, распакуйте, например, в `C:\TwitchAlarm\bookish-umbrella`. |
| Git | Планируете позже получать обновления одной командой | В PowerShell выполните `git clone --branch fix/reliable-twitch-monitoring https://github.com/Bronyatenei/bookish-umbrella.git C:\TwitchAlarm\bookish-umbrella`. Для обновления потом используйте `git pull`. |

В результате нужен каталог:

```text
C:\TwitchAlarm\bookish-umbrella\home-agent
```

Если папка лежит в `Downloads`, лучше перенесите её в `C:\TwitchAlarm`. Так Windows не будет очищать её, а путь для автозапуска останется постоянным.

## 2. Установите Node.js

1. Откройте [nodejs.org](https://nodejs.org/) и скачайте **LTS**-версию Node.js. Для текущей версии Firebase Admin SDK нужна Node.js **22 или новее**.[1]
2. Запустите установщик. В стандартных настройках оставьте включённым пункт добавления Node.js в `PATH`.
3. Закройте все открытые окна PowerShell, откройте новое и выполните:

```powershell
node --version
npm --version
```

Первая команда должна вывести версию `v22...` или выше. Если Windows пишет, что `node` не распознана как команда, перезагрузите Windows либо повторите установку Node.js с включённым `PATH`.

## 3. Создайте и сохраните Firebase-ключ для ПК

1. Откройте Firebase Console: <https://console.firebase.google.com/project/twitch-alarm-a5ae5/settings/serviceaccounts/adminsdk>.
2. В разделе **Firebase Admin SDK** нажмите **Generate new private key**.
3. В окне предупреждения нажмите **Generate key**. Браузер скачает JSON-файл.
4. Переместите скачанный файл в:

```text
C:\TwitchAlarm\bookish-umbrella\home-agent\service-account.json
```

Если у файла другое имя, переименуйте его **ровно** в `service-account.json`.

Firebase выдаёт ключ сервисного аккаунта именно для запуска Admin SDK в доверенной среде; храните его как пароль.[2] Если ключ когда-либо оказался в чате, облачном диске с публичной ссылкой или GitHub, удалите его в Firebase/Google Cloud и создайте новый.

## 4. Настройте телефон

Сначала установите последнюю APK Twitch Alarm и один раз откройте приложение при подключённом интернете.

1. На главном экране добавьте все нужные Twitch-каналы. Логины должны совпадать с теми, которые позднее внесёте в `config.json`.
2. Включите тумблер каждого нужного стримера. Выключенный тумблер означает, что тревога для этого канала не запускается, даже если ПК отправил событие.
3. Откройте **Настройки**.
4. В блоке стратегии выберите **«Домашний агент — проверки на ПК»**.
5. Дождитесь строки **«FCM-токен готов: …»** и нажмите **«Скопировать FCM-токен»**.
6. Разрешите приложению показывать уведомления, если Android спросит об этом. Не ограничивайте приложение жёстким режимом экономии батареи во время первых тестов.

> FCM-токен привязан к конкретной установке приложения и может поменяться после переустановки, очистки данных или смены устройства. Если Home Agent внезапно начал сообщать о недействительном токене, снова откройте настройки приложения, скопируйте текущий токен и замените его в `config.json`.[3]

## 5. Создайте `config.json`

1. Откройте PowerShell и перейдите в папку агента:

```powershell
cd C:\TwitchAlarm\bookish-umbrella\home-agent
Copy-Item config.example.json config.json
notepad config.json
```

2. Вставьте скопированный с телефона FCM-токен вместо `PASTE_DEVICE_FCM_TOKEN_HERE`.
3. В массиве `channels` перечислите логины Twitch **без URL, `@` и пробелов**. Используйте нижний регистр.

Пример структуры файла:

```json
{
  "firebaseServiceAccountPath": "./service-account.json",
  "fcmToken": "вставьте_сюда_полный_токен_из_приложения",
  "pollIntervalSeconds": 60,
  "channels": [
    "bellmarytank",
    "tyuuba",
    "maku_q"
  ]
}
```

Поле `pollIntervalSeconds` задаёт интервал между проверками. Значение `60` — хороший первый вариант. Значения ниже `15` секунд агент автоматически поднимет до `15` секунд. Не вставляйте комментарии в JSON и не меняйте `firebaseServiceAccountPath`, если ключ лежит рядом с `config.json` под именем `service-account.json`.

## 6. Установите зависимости и проверьте FCM без настоящего стрима

В той же папке выполните:

```powershell
npm ci
npm run test:fcm -- bellmarytank
```

Замените `bellmarytank` на **логин, который уже добавлен и включён в приложении**. Команда `test:fcm` не обращается к Twitch: она отправляет специальное FCM-событие с новым идентификатором и должна сразу включить на телефоне тревогу с подписью **«Тест Home Agent»**.

Условия успешного теста:

| Условие | Как проверить |
|---|---|
| Home Agent выбран в приложении | Настройки → «Домашний агент — проверки на ПК» |
| Канал совпадает | Указанный логин есть и включён на главном экране Twitch Alarm |
| FCM-токен актуален | В `config.json` вставлен токен из кнопки «Скопировать FCM-токен» |
| Телефон доступен | Есть интернет, приложению разрешены уведомления |
| Firebase-ключ верный | `service-account.json` получен из того же проекта `twitch-alarm-a5ae5` |

Успешный PowerShell вывод выглядит так:

```text
Test FCM sent for bellmarytank. Firebase message ID: projects/...
The phone should start the alarm if Home Agent mode is selected and this streamer's toggle is enabled.
```

После проверки выключите тревогу на телефоне обычной кнопкой. Команда теста ничего не меняет в `state.json` и не ждёт запуска стрима.

## 7. Запустите настоящую проверку Twitch

Запускайте агент из той же папки:

```powershell
npm start
```

Ожидаемый начальный вывод:

```text
Home Agent started; checking 3 channel(s) every 60s.
The first successful poll only initializes state; alarms are sent on offline -> online transitions.
... checked: bellmarytank=offline, tyuuba=offline, maku_q=offline; heartbeat=sent
```

Последующие успешные проверки показывают либо `heartbeat=sent`, либо, например, `heartbeat=next in 3m`. Это позволяет отличить работающий обновлённый Agent от старой версии и видеть, когда телефон должен получить очередное подтверждение.

Первая удачная проверка только создаёт `state.json` и **не должна** включить тревогу для уже идущего стрима. Далее агент отправляет FCM лишь при обнаружении перехода `offline → LIVE`. Это исключает ложную тревогу после перезапуска агента.

После успешной Twitch-проверки агент также отправляет отдельный heartbeat не чаще одного раза в **5 минут**. Он не включает будильник. Его принимает телефон, чтобы определить, работает ли ПК, сам процесс Agent, сеть и Twitch-проверка. Ничего добавлять в `config.json` для heartbeat не нужно.

### Подстраховка на телефоне

В приложении выберите **Настройки → Домашний агент — проверки на ПК**. Ниже появится блок **«Подстраховка Home Agent»**. В нём можно выбрать период контроля телефона (5/10/15/20/25 минут), указать допустимое число пропусков, выбрать резервную стратегию **Надёжный** или **Экономия** и включить автоматический возврат после восстановления ПК.

Например, период контроля `10 минут` и порог `2` означают: если телефон не увидит свежий heartbeat примерно 20 минут, он сохранит выбранный режим Home Agent, но запустит выбранную локальную стратегию. После двух новых heartbeat автоматический возврат выключит локальный fallback; при выключенном автоматическом возврате появится кнопка ручного возврата.

Для наиболее точного контроля на Android 12+ нажмите **«Разрешить точный контроль»** в этом же блоке и включите системный доступ **«Будильники и напоминания»**. Без доступа Android всё равно выполняет watchdog, но при Doze может отложить фактическую проверку.

Для остановки в PowerShell нажмите `Ctrl+C`. Файл `state.json` сохранится рядом с `config.json`. Удаляйте его только если сознательно хотите заново зафиксировать текущие состояния каналов при следующем запуске.

## 8. Настройте автозапуск в Windows

Сначала создайте в `home-agent` файл `start-home-agent.cmd` через Блокнот:

```bat
@echo off
cd /d "C:\TwitchAlarm\bookish-umbrella\home-agent"
call npm.cmd start >> "%~dp0home-agent.log" 2>&1
```

Если вы выбрали другой каталог, замените путь во второй строке. Файл `home-agent.log` будет содержать обычные проверки и ошибки агента.

Выберите один из способов автозапуска.

| Способ | Плюсы | Ограничения |
|---|---|---|
| Папка «Автозагрузка» | Самая простая настройка | Не перезапускает агент после сбоя; запуск происходит только после входа пользователя в Windows |
| Планировщик заданий Windows | Может перезапускать процесс после сбоя, есть ручной запуск для диагностики | Настроек больше |

### Вариант A: папка «Автозагрузка»

1. Нажмите `Win + R`, введите `shell:startup` и нажмите Enter.
2. Создайте в открывшейся папке ярлык на `C:\TwitchAlarm\bookish-umbrella\home-agent\start-home-agent.cmd`.
3. Перезайдите в учётную запись Windows или запустите ярлык двойным нажатием.
4. Проверьте файл `home-agent.log` в папке агента.

### Вариант B: Планировщик заданий Windows

1. Нажмите `Win`, найдите и откройте **Планировщик заданий**.
2. Справа выберите **Создать задачу**, а не «Создать простую задачу».
3. Во вкладке **Общие** задайте имя `Twitch Alarm Home Agent` и выберите **Выполнять только для вошедшего пользователя**.
4. Во вкладке **Триггеры** нажмите **Создать** → «Начать задачу: При входе в систему» → выберите свою учётную запись → **ОК**.
5. Во вкладке **Действия** нажмите **Создать** и заполните:

| Поле | Значение |
|---|---|
| Действие | Запуск программы |
| Программа или сценарий | `C:\Windows\System32\cmd.exe` |
| Добавить аргументы | `/c ""C:\TwitchAlarm\bookish-umbrella\home-agent\start-home-agent.cmd""` |
| Рабочая папка | `C:\TwitchAlarm\bookish-umbrella\home-agent` |

6. Во вкладке **Условия** снимите «Запускать только при питании от электросети», если это ноутбук и вы хотите проверки от батареи.
7. Во вкладке **Параметры** включите «Если выполнение задачи завершилось с ошибкой, перезапускать через» и укажите `1 минуту`, например `3` попытки. Для правила «Если задача уже выполняется» выберите **Не запускать новый экземпляр**.
8. Нажмите **ОК**, затем выделите задачу в библиотеке планировщика и нажмите **Выполнить**. Проверьте `home-agent.log`.

ПК должен оставаться включённым и подключённым к интернету. Если он спит, выключен или Windows ещё не вошла в учётную запись, агент Twitch не проверяет. На телефоне в это время локальный режим Home Agent не выполняет заменяющие проверки — это осознанный обмен заряда телефона на зависимость от ПК.

### Полностью скрытый запуск без окна на панели задач

Если вы не хотите видеть даже свёрнутое окно, используйте файл `run-home-agent-hidden.vbs`, который находится рядом с `agent.mjs`. Он запускает ваш `start-home-agent.cmd` скрыто и при этом ждёт завершения процесса, поэтому Планировщик продолжает видеть работу агента и может применить правило перезапуска при сбое.

В свойствах задачи замените действие на следующие значения:

| Поле | Значение |
|---|---|
| Программа или сценарий | `C:\\Windows\\System32\\wscript.exe` |
| Добавить аргументы | `"C:\\TwitchAlarm\\bookish-umbrella\\home-agent\\run-home-agent-hidden.vbs"` |
| Рабочая папка | `C:\\TwitchAlarm\\bookish-umbrella\\home-agent` |

Замените путь на свой, если вы распаковали агент в другую папку. Остановите ранее открытое окно Home Agent через `Ctrl+C`, сохраните задачу и нажмите **Выполнить**. Нового окна или значка на панели задач быть не должно. Через 70 секунд откройте `home-agent.log`: появление свежей строки `checked: ...` подтверждает работу скрытого процесса.

> Не устанавливайте `wscript.exe` как действие вместе с `agent.mjs` напрямую: нужен именно `run-home-agent-hidden.vbs`, который запускает существующий `.cmd`-файл, сохраняет журнал и возвращает Планировщику код завершения.

## 9. Диагностика

| Симптом | Вероятная причина и решение |
|---|---|
| `node` или `npm` не распознана | Закройте и заново откройте PowerShell; при необходимости переустановите Node.js 22 LTS с включённым `PATH`. |
| `Cannot find package 'firebase-admin'` | Выполните `npm ci` именно внутри папки `home-agent`. |
| `ENOENT ... service-account.json` | Поместите ключ в `home-agent` и назовите его `service-account.json`, либо исправьте путь в `config.json`. |
| `Set config.fcmToken...` | Скопируйте FCM-токен из настроек приложения и вставьте его целиком в `config.json`. |
| Тест сообщает, что FCM отправлен, но тревоги нет | Убедитесь, что выбран Home Agent, логин совпадает с включённым стримером, телефон подключён к интернету и уведомления разрешены. |
| Ошибка о недействительном/незарегистрированном токене | Скопируйте новый токен из приложения; при необходимости откройте приложение при интернете и повторите. |
| Ошибка Firebase `SenderId mismatch` или `credential` | Ключ и FCM-токен получены из разных Firebase-проектов. Создайте ключ в проекте `twitch-alarm-a5ae5` и снова скопируйте токен. |
| `Twitch HTTP ...` или `Twitch GraphQL ...` | Проверьте интернет ПК. Агент повторит попытку на следующем интервале; ошибки и обычные проверки записываются в `home-agent.log` при автозапуске. |
| Агент не отправляет сигнал для уже идущего стрима | Это нормально: первая проверка записывает состояние. Сигнал возникает только после следующего перехода канала из offline в live. |

## 10. Обновление Home Agent

Перед обновлением остановите работающий агент (`Ctrl+C`) или завершите задачу в Планировщике. Затем:

```powershell
cd C:\TwitchAlarm\bookish-umbrella
# Если использовался Git:
git pull
cd home-agent
npm ci
```

При обновлении из ZIP распакуйте новую версию в отдельную папку, а затем перенесите в неё **только** локальные файлы `config.json`, `service-account.json` и при необходимости `state.json`. Не заменяйте их чужими файлами из интернета.
